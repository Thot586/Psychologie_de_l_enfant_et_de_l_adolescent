J'ai remarqué quelque chose : six chemins, une règle commune
À partir de « j'ai remarqué quelque chose », six chemins : mon enfant est harcelé ; mon enfant harcèle ; mon enfant est témoin ; j'encadre un groupe où ça se passe ; ce n'est pas mon enfant (voisin, neveu, enfant confié) ; l'auteur est un adulte de l'école. Règle commune : protéger d'abord, qualifier ensuite.
