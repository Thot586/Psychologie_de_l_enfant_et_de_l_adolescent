Comment lire ce site

  • Deux niveaux de lecture dans la même page. Le texte principal se suffit à lui-même. Les encadrés « Approfondir » donnent la source, la méthode et le chiffre exact ; on peut les sauter sans perdre le fil, ou les masquer d'un geste dans les réglages.
  • Les sources sont indiquées. Chaque référence porte un lien vers l'article, le rapport ou la page officielle. Le niveau de preuve de chaque affirmation est indiqué.
  • Un glossaire relié au texte. Les termes techniques sont soulignés en pointillé : survolez ou touchez pour lire la définition courte, ouvrez pour la définition complète et sa source, puis revenez exactement là où vous lisiez.
  • Utilisable hors ligne. Après une première visite, les pages consultées restent disponibles ; les réglages permettent d'enregistrer toute une session sur le téléphone.
